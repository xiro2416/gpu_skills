# 本机 RTX 4090 / SM89 / 约 48 GiB

条件：2026-10-05，dense，常量输入，8192³/16384³，400 W；未见温度限频，有功率限频。

## 资源

| 项目 | 值 |
|---|---|
| 架构 / SM | Ada SM89 / 128 |
| 显存 | 驱动 49140 MiB；CUDA 可见 47.37 GiB |
| L2 / 显存总线 | 72 MiB / 384 bit |
| CUDA / Tensor Cores | 16384 / 512（由 SM 数和架构推导） |
| 每 SM 最大驻留线程 / warp / block | 1536 / 48 / 24；warp=32 threads |
| 每 block 最大线程 | 1024 |
| 32-bit 寄存器上限 | 65536/SM、65536/block、255/thread |
| Shared memory 上限 | 100 KiB/SM；48 KiB/block 默认、99 KiB/block opt-in |
| 统一 L1/shared/texture | 128 KiB/SM，shared 占用其中容量 |
| Warp schedulers | 4/SM |
| PCIe 最大能力 | Gen4 ×16 |
| 驱动 / CUDA / cuBLAS | 595.71.05 / 13.2 / 13.4.0 |
| 实测带宽（GB/s） | Triad **938.07**；Copy 919.66 |

## 实测性能

| 输入精度 | 累加 → 输出 | Roof 规模 | Roof | Ridge | 功耗 W（16384³） |
|---|---|---:|---:|---:|---:|
| FP32 | FP32 → FP32 | 8192³ | 55.50 | 59.16 | 376.1 |
| FP16 | FP32 → FP16 | 8192³ | 168.58 | 179.71 | 未测 |
| FP16 | FP16 → FP16 | 16384³ | 290.74 | 309.93 | 326.6 |
| FP8 E4M3 × E4M3 | FP32 → FP16 | 16384³ | 343.61 | 366.30 | 376.7 |
| signed INT8 × INT8 | INT32 → INT32 | 16384³ | **635.70** | **677.67** | **399.9** |

TF32、BF16 及其他精度：本版本未建立 Roof。数值校验为常量输入抽查；FP8 `FAST_ACCUM=0`。

## 能力

- 已执行：表内 cuBLAS/cuBLASLt 路径；FP32/FP16 为 NN，FP8/INT8 为 TN。
- 仅编译验证：FP16/BF16/TF32、FP8 E4M3/E5M2、INT8/INT4/binary warp MMA，以及 `cp.async`。
- 无原生 FP6/FP4 Tensor、TMA、TMEM/`tcgen05`；INT4 不等于 FP4。
- NCU 受权限限制；SM 覆盖、CTA/waves 和管线效率待验证。
