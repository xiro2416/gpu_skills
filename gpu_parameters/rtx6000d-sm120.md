# NVIDIA RTX 6000D / SM120

条件：2026-10-05 v2，dense，结构化输入，16384³，600 W；未见功率或温度限频。

## 资源

| 项目 | 值 |
|---|---|
| 架构 / SM | Blackwell SM120 / 156 |
| 显存 | 标称 84 GB；测试可见 83.049 GiB |
| L2 / 显存总线 | 112 MiB / 448 bit |
| SM 时钟 | 最大 2430 MHz；测试稳定窗口约 2422 MHz |
| 驱动 / CUDA / CUTLASS | 595.71.05 / 13.2 / 4.8.0 |
| 实测带宽（GB/s） | Triad **1311.1**；Copy 1277.9 |

## 实测性能

| FP32 | FP32 → FP32 | 67.87 | 51.77 | 485.9 |
| FP32 输入降为 TF32 | FP32 → FP32 | 72.16 | 55.04 | 309.4 |
| FP16 | FP32 → FP32 | 144.02 | 109.85 | 325.4 |
| BF16 | FP32 → FP32 | 144.02 | 109.85 | 323.1 |
| FP8 E4M3 × E4M3 | FP32 → BF16 | 287.57 | 219.35 | 362.8 |
| FP8 E5M2 × E4M3 | FP32 → BF16 | 287.48 | 219.28 | 370.6 |
| signed INT8 × INT8 | INT32 → INT32 | 287.80 | 219.52 | 365.6 |
| MXFP6 E2M3 × E2M3 | FP32 → BF16 | 367.47 | 280.29 | 459.0 |

FP8 `FAST_ACCUM=0`；MXFP6 使用 UE8M0 per-32 scale，NVFP4 使用 UE4M3 per-16 scale；测试 scale=1。

## 能力

- 已执行：warp-level `mma.sync`、TMA、`mbarrier`、CUTLASS warp-specialized schedule，以及表内低精度路径。
- SM120 不采用 SM100 的 TMEM/`tcgen05`；本卡记录 cluster=1×1×1，无程序化 TMA multicast。
- NCU 代表 kernel 支持 156/156 SM 曾参与；不代表同时饱和。
- 寄存器、shared memory 和驻留上限：当前画像未记录，选 tile 前查询实际设备。
